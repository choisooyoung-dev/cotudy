cotudy — 물류회사에서 일하며 배우는 코딩

화장품 물류회사 물류팀에 갓 입사한 김사원이 되어 물류센터를 돌아다니며, 동료들이 부탁하는 일을 Java, JavaScript, Python 코드로 해결하는 무료 3D 코딩 공부 게임이에요.

  • 설치 없이 브라우저에서 코드를 직접 쓰고, 진짜로 실행해서 채점해요.
  • 개념 공부 → 출력 예상 → 빈칸 채우기 → 직접 쓰기 순서로, 코딩을 처음 하는 사람도 할 수 있어요.
  • 배우는 것: 출력, 변수와 타입, 연산자, 조건문, 반복문, 배열·리스트, 문자열, 함수, 맵·딕셔너리, 클래스와 객체, 예외 처리 (언어마다 29개 퀘스트)
